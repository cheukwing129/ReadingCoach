# 教師操作、部署與回滾

## 上課前

1. 真題管理打開來源，確認學生已完成的年份；已做過的題可用作重練，不能算全新自主表現。
2. 課堂建立作業包、選題及支援設定。下載檔案，經現有校內渠道交給學生。網站不會自動寄送。
3. 學生匯入作業包，用固定代號保存與交卷。教師收取JSON交卷包後，可一次選多檔匯入；已匯入版本不重複建立。
4. 點「教師：逐句診斷」，先讀首答與這次提交；選學生原句及原文段落，寫有依據的觀察與修訂動作。至少一則定位標註才可輸出回饋。
5. 學生匯入回饋包，在原作業修改再交。改寫不覆蓋首答，舊回饋不會冒充新答案的確認。換瀏覽器可同時匯入作業、自己的交卷及回饋，恢復作答。

教師未完成的回饋表會保存在本機，可重新整理或離開再返回。教師評分是整道原題分數，不是教練自檢欄加總；詳細分題依據仍展示原文件的分值及評分參考。

## 管理真題

匯出已核對真題包作為schemaVersion 2範本。每題至少有正式考試年份、原題號、完整原文、原題/分題分值、三類來源Drive fileId及PDF頁碼、官方評分資料、核對狀態及版本。只有教師對照來源後確認的白話真題可供學生使用。

新匯入即使標為ready，也先進入待核對。不能覆寫相同識別碼的不同題目或原文版本；修訂資料須另用識別碼，以保留舊答案的題目版本。教師補充講解獨立保存，不改來源評分。

投影頁及管理內的學生視角預覽不寫入學生作答/支援紀錄。學生自行開啟答案或提示則記錄支援時間。

## 保存與衝突

- 定期在「學習記錄」匯出完整備份，包含修補、作業、提交、回饋、講解及衝突封存版本。
- 不要把完整個人備份當作交卷包；交卷包只包含該作業的作答。
- 多分頁衝突時，先匯出本頁，再選採用另一分頁或保留本頁。選保留本頁時另一版本封存於備份的 `academy.conflicts`。
- 儲存失敗/拒絕時仍可在記憶體作答及下載備份，離開或重新整理前先匯出。網站沒有雲端副本。
- 外層version 1保留舊備份格式；新模組為academy.schemaVersion 2。舊版未追蹤支援時點的答案標示未知，不補造自主首答。

## 部署

維持原Cloudflare Pages靜態部署，輸出目錄 `dist`，無建置命令、無環境變數。根目錄入口供本機預覽，並與dist入口同時更新。不要只上傳HTML；十個JS檔及CSS須同一提交部署。

目前沒有後端/模型服務。若日後加入雲端功能，需獨立建立身份權限、資料庫及服務端模型代理；不可把模型金鑰放在前端。這些服務不屬本次已實作功能。
