# Lumen UI 全站設計

參照使用者選定的Lumen demo，更新正式網站的全部公開流程。

- 青綠semantic tokens、白底閱讀／教學卡片、宋體標題、1280px以上的固定側欄。
- 首頁與年份目錄使用真實篇章及完成數；新增年份快捷選項。
- 文章頁有段落索引及字體調整；分析保持預設關閉。
- 題型、作答、評分及解析共用一致的控制、分題分組及留白。
- 元件只註冊Button/Card，打包6,485 bytes；CSS為Lumen官方4.0.0 stylesheet。
- 原文、題目、評卷資料、完成條件和既有草稿storage key沒有修改。
- 原有sticky題目、原文定位、跨篇切換及橫直屏分頁管理保留。
- 動畫沒有持續播放；尊重減少動態設定。主容器與sticky祖先沒有transform。
