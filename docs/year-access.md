# 年份密碼

`dist/year-access-config.js` 只存年份密碼及教師通行碼的 SHA-256 雜湊。2012–2030 年已按「不同英文名＋年份」設定預設密碼；明文不會放進網頁或設定檔。

要修改某年的密碼，或替新增年份設定密碼，在本機執行以下命令。終端機會隱藏輸入，只把雜湊印出：

```sh
python3 -c 'import getpass,hashlib; print(hashlib.sha256(getpass.getpass("新密碼：").encode()).hexdigest())'
```

輸入該年的「英文名＋年份」密碼，將輸出的雜湊新增或貼到 `years` 下相應年份的欄位。教師通行碼則替換 `teacher` 的雜湊。新增年份時延用「不同英文名＋年份」格式，並只提交雜湊；不要將密碼原文貼進程式碼、測試或文件。

解鎖狀態存在瀏覽器的 `localStorage`。學生解鎖某年後，此瀏覽器不會再問該年的密碼；輸入教師通行碼後，此瀏覽器會記住全部年份。清除網站資料或更換瀏覽器後需重新輸入。

此機制只控制靜態網站的介面入口。由於文章資料隨前端程式下載，熟悉開發者工具的人仍可直接取得資料；不要用來保護機密內容。
