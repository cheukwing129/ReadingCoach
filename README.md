# 閱讀理解答題教練 ReadingCoach

正式網站：[閱讀理解答題教練](https://readingcoach.pages.dev/#home)

香港高中中文閱讀理解工具。**學生入口只使用正式 DSE 白話文原文、原題及來源評分資料**；不使用文言、指定課文、模擬題或原創練習作新教學。教練提示、修訂追問與能力配對另行標示，不當成官方評分條目。

## 學生流程

- 首次開題只呈現原文、原題及原作答欄。保存首答後可自行重寫，再選擇開啟提示或評分參考；首答與最近10個修訂版本分開保存。
- [失分修補站](https://readingcoach.pages.dev/#repairs)：2024第13、15、20題各3個真實評卷舉隅。先診斷、選證據及重寫，保存後才揭示來源分數和修訂指引。
- [跨年挑戰](https://readingcoach.pages.dev/#challenge)：6道跨年真題。配對依據包含共同能力及題目差異；未有本機接觸紀錄不等於未曾做過，學生可申報已接觸。
- [能力與重練](https://readingcoach.pages.dev/#abilities)：作用、主旨、感情三個範疇。自檢、字數、開啟講解及同題重寫不產生掌握證明。最高狀態須兩篇不同文本的完整自主首答，並有綁定答案及題目版本的教師覆核。課堂記錄按學生代號隔開。
- 預設完成後第3、7天顯示站內重練建議，按香港日期計算；可調整間隔，沒有推播通知。
- 原有3組原創材料、9道題只保留歷史答案及備份相容性，退出新練習、推薦、派題與能力判斷。

## 教師及課堂

[課堂](https://readingcoach.pages.dev/#classroom)使用離線檔案交換：

1. 教師選真題，建立固定題目版本的**作業包**，設定自主作答或保存首答後開放支援。
2. 學生匯入、填代號、作答及選證據，下載只含本作業答案與歷程的**交卷包**。
3. 教師批次匯入交卷，逐句連結學生原句及原文段落，填寫已有內容、缺口和下一步，可選只給追問。教師評分按原題滿分，與自檢項目數無關。
4. 教師下載**回饋包**交給學生。學生匯入後修訂及重交；舊回饋保留並標示適用的提交版本。

三種包可同批匯入，按依賴次序處理。相同包重複匯入會略過；同一識別碼不同內容會拒絕覆寫。學生及教師代號未驗證，不是登入帳戶。作業檔內含來源評分資料，支援限制用於學習流程，不能視作保密考試機制。

[真題管理](https://readingcoach.pages.dev/#teacher)可匯出/匯入schemaVersion 2真題包、預覽、修改獨立的教練補充講解。新匯入內容先待核對；教師對照來源後確認，才進入學生題庫。既有題目或原文的不同版本不會覆寫，須使用新識別碼。

[投影示例](https://readingcoach.pages.dev/#project/dse2024-q13)逐步揭示原題、證據、推論、落筆及來源失分案例；支援左右方向鍵，不顯示個人答案，也不更改學生支援或能力記錄。

**目前沒有雲端同步、帳戶/班級身份驗證或AI自動診斷。** 未配置後端及模型服務，完整的人工回饋與離線課堂流程已可用。[教師操作及部署/回滾說明](docs/teacher-and-deployment.md)。

## 資料保護

所有學習資料存於本機 `localStorage` 的 `dse-reading-coach-v1`。外層version 1兼容舊備份，新增模組為 `academy.schemaVersion: 2`。學習記錄可匯出/還原完整備份；課堂交換包不包含其他練習。

多分頁寫入前檢查已保存版本，遇衝突暫停保存，讓使用者匯出本頁、採用另一分頁，或保留本頁並封存另一版本。儲存被拒或容量不足時保留記憶體內容並提示備份；匯出後再離開。備份不包含登入或伺服器憑證。

## 本機開發與驗證

原生HTML/CSS/JavaScript，無建置依賴。根目錄及 `dist/index.html` 兩個入口共用 `dist` 的程式與資料。

```sh
python -m http.server 8080
node --test tests/*.test.cjs
```

瀏覽器測試需本機 Chromium 及 Playwright：

```sh
PLAYWRIGHT_MODULE_PATH=/path/to/playwright-core BROWSER_EXECUTABLE_PATH=/path/to/chromium node scripts/browser-smoke.cjs
PLAYWRIGHT_MODULE_PATH=/path/to/playwright-core BROWSER_EXECUTABLE_PATH=/path/to/chromium node scripts/academy-browser-smoke.cjs
```

可設定 `BROWSER_QA_OUTPUT_DIR` 保存畫面。測試環境需繁體中文字型，否則無法可靠核對中文排版。來源指紋、資料結構、能力證據與交換包測試見 `tests/academy.test.cjs`；[本次驗證及已知邊界](docs/2026-10-11-update.md)。
