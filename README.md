# 閱讀理解答題教練 ReadingCoach

正式網站：[閱讀理解答題教練](https://readingcoach.pages.dev/#home)

香港高中中文閱讀理解的分步練習工具。內置 **2024 DSE 李娟《繁盛》真題練習：15段原文、第9–20題、12題共35分**，並保留 **3組原創材料、9道練習**；第三組原創材料為甲乙雙篇。

首頁選「開始《繁盛》練習」，或在網址後加入 `#exercise/dse2024-fansheng` 查看整份練習。真題資料及答案依使用者提供的Google Drive文件，核對記錄見 [來源說明](docs/2024-fansheng-sources.md)。

「逐題精講」可直接閱讀第9–20題的完整解題示範；入口為 `#coaching/dse2024-q9`。不必先填答案，也不會把閱讀精講算成已作答、已核對或已完成。

已按《繁盛》學生模擬測試報告改善流程，詳見 [改善與驗證紀錄](docs/2026-10-10-test-improvements.md)。新真題練習預設先自主試答；已開啟的舊草稿沿用教練模式及原有記錄。

## 功能

- 四步練習：拆題、選取文本證據、組織答案、自檢。
- 「自主試答／教練引導」兩種模式。自主頁先顯示原文、原題與答案欄；保存首答後再取用支援。總覽教學也須主動開啟，分開記錄指引、每級提示、精講及來源答案的首次查看時點。
- 保存首答、最近10個修訂版本及修改理由，並可比較首答與目前答案。查看支援0級不等同自主作答；舊資料未追蹤的查看時點不會補造。
- 真題自檢可圈選自己答案中的支持句，並用深化追問檢查推論。第13、15、20題有貼題追問；可保存老師或同學的覆核意見。自檢、圈句及追問不作語意判分。
- 證據回饋說明線索的角色；「原文線索 → 推論 → 回應題目」筆記協助補上關係，步驟檢查提醒未填的層次。第9題的困境背景證據可用，但仍須連到直接觸發及感情釋放。
- 段落導航、返回題目範圍／已選證據及閱讀位置保存，減少來回找原文。通用原則初始聚焦一類，核對後精講細節預設收起。
- 分開顯示已檢視、已做到、不確定與未做到；可直接返回仍需重溫的項目。完成後提供尚未試過的不同文本同類原創題，先自主作答，再查看例答。
- 21道內置題目共用16項通用處理原則，按「記敘、描寫、說理」分類，涵蓋概括、語境釋義、因果、人物分析、變化、比較、象徵、修辭、作用、篇章結構、主旨、篇名、論證與評析。同一原則可出現在多類，勾選及取消會同步，已選項目只計一次；各類可收起／展開。學生依題幹辨別適用項目，核對回饋區分「必須處理」與「可輔助思考」。教師新建題目的分類設定也同步。
- 拆題只保留處理原則，已移除內容重複的「這道題主要要求你做甚麼」選擇題；核對不再要求另選主要指令。
- 點選原文句子，保存答案草稿，逐級展開最多三級提示。
- 真題保留選擇、判斷、表格、短答及長答格式；先試答，再核對文件答案、評分資料及證據分析。
- 證據分析中的原文引文可一鍵加入標註器，包含跨多個句子的引文。
- 12題共50個解題步驟、73處原文引文，逐步連接字面觀察、推論與答案；所有客觀題逐項排除干擾選項。
- 34個文件不足分／零分舉隅，分別說明可能的誤讀、失分原因與修補步驟；第13、15、20題另拆解文件4分舉隅的組織。
- 每題提供貼合題型的落筆次序、通用方法、可遷移框架、額外技巧與口頭自測。精講細節可展開／收起。
- 整份《繁盛》練習可下載原文／原題文字稿，以及獨立的答案／教練分析稿。
- 分步作答與自由作答各自保留草稿。首次切換到自由作答時帶入分步答案。
- 比較不同程度例答，逐項自檢，記錄需要改進的地方。
- 修改答案後清除舊自評及完成標記，按新答案重新檢查。
- 教師可新增文章、題目、評分要點、提示及例答，並匯入／匯出題庫。
- 學習記錄可匯出文字報告，完整 JSON 備份可還原題庫、草稿及自評。

## 評分與資料

原創及教師新增練習，每個要點以1分作教學自檢。自評分數表示學生自行確認的答案要素，**並非正式DSE評分或評級**。

2024《繁盛》保留原卷分值：客觀題按文件中的選項核對，書面題展示來源答案及評分準則，仍須教師評閱。真題的教練自檢分開記錄已檢視及各種判斷的項目數，**不換算成原題分數**。系統不作書面答案語意評分，亦不依關鍵詞給分。新真題記錄中，選「已做到」須圈選答案支持句；選「不確定／未做到」也能完成。修改答案會清除舊來源核對、自檢支持句及完成標記，但保留首答與已保存的版本。

低分例的原答案與分數來自文件；「可能怎樣想到」及修訂分析由教練新增，不代表實際考生的出現次數或比例。長答按整體品第評閱；教練框架不是逐空一分的評分表，也不要求唯一分析方向。

證據回饋依選句提供參考角色與解釋，不自動評定答案正確；合理的索引外證據也可接受。

草稿、教師題庫和記錄儲存在瀏覽器 `localStorage`，不會自動跨裝置同步。換裝置或清除瀏覽器資料前，請先匯出完整備份。

通用原則以固定識別碼保存。分類更新沿用原有識別碼，既有勾選、答案、證據、自檢及完成記錄均保留；更早期以選項位置保存的內置拆題勾選，在首次轉用通用原則時會重設。舊式教師題庫仍可匯入及編輯；舊「主要指令」選擇已不參與核對。拆題核對只供學習，不計入真題分數。

## 本機使用

沒有前端套件或建置依賴。可直接開啟 `dist/index.html`；建議以本機靜態伺服器開啟，讓瀏覽器穩定保存資料：

```sh
python3 -m http.server 8080 --directory dist
```

然後瀏覽 `http://localhost:8080`。

## 靜態託管

沒有建置步驟，可部署至Cloudflare Pages或其他靜態服務。輸出目錄可選 **`dist`**；也可發布repo根目錄，根目錄 `index.html` 已載入 `dist` 內資源。兩個入口載入相同的真題與教練功能。

本 repo 提供網站原始碼；託管平台的存取權限及部署設定另行配置。

## 驗證

使用支援 `node:test` 的 Node.js：

```sh
node --test tests/*.test.cjs
node --check dist/app.js
node --check dist/core.js
node --check dist/exam.js
node --check dist/dse2024-data.js
node --check dist/dse2024-coaching.js
```

目前有57項程式與資料流程檢查，涵蓋已核對來源的文字指紋、35分及分題分值、客觀題答案及全選項解釋、73處精講引文、34個來源低分舉隅、精講直接閱讀／標註／作答記錄隔離、完整下載稿、真題核對／修訂流程、草稿還原、共用拆題原則／三類交集／跨類別同步勾選與教師設定／輔助方法／舊資料相容、原創練習、教師題庫及Cloudflare兩個入口的資源路徑。新增檢查包括自主試答隱藏指引、首答不可被修訂覆寫、支援及每級提示查看紀錄、自檢圈句、正確的自檢統計、版本／閱讀位置還原、證據角色、推論步驟及跨篇自主試答。
