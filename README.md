# 閱讀理解答題教練 ReadingCoach

香港高中中文閱讀理解的分步練習工具。第一版有 **3 組原創閱讀材料、9 道練習**；第三組為甲乙雙篇，集中訓練人物推論、引文作用及比較。

## 功能

- 四步練習：拆題、選取文本證據、組織答案、自檢。
- 點選原文句子，保存答案草稿，逐級展開最多三級提示。
- 分步作答與自由作答各自保留草稿。首次切換到自由作答時帶入分步答案。
- 比較不同程度例答，逐項自檢，記錄需要改進的地方。
- 修改答案後清除舊自評及完成標記，按新答案重新檢查。
- 教師可新增文章、題目、評分要點、提示及例答，並匯入／匯出題庫。
- 學習記錄可匯出文字報告，完整 JSON 備份可還原題庫、草稿及自評。

## 評分與資料

每個要點在本工具中以 1 分作教學自檢。自評分數是學生自行確認的答案要素，**並非正式 DSE 評分或評級**。系統不作語意評分，不依關鍵詞判定答案正確；正式分數仍須由教師評閱。

證據範圍提示只檢查選取句子是否觸及預設原文範圍，合理的其他證據也可接受。

草稿、教師題庫和記錄儲存在瀏覽器 `localStorage`，不會自動跨裝置同步。換裝置或清除瀏覽器資料前，請先匯出完整備份。

## 專案結構

```text
dist/
  index.html   網頁入口
  styles.css   響應式介面
  data.js      原創文章、題目、提示與例答
  core.js      題庫驗證、作答和自評邏輯
  app.js       作答流程、記錄、教師編輯及備份
tests/
  core.test.cjs
  app-smoke.test.cjs
```

## 本機使用

沒有前端套件或建置依賴。可直接開啟 `dist/index.html`；建議以本機靜態伺服器開啟，讓瀏覽器穩定保存資料：

```sh
python3 -m http.server 8080 --directory dist
```

然後瀏覽 `http://localhost:8080`。

## 靜態託管

發布目錄為 **`dist`**，不需要建置指令，可部署至支援靜態 HTML/CSS/JavaScript 的託管服務。

本 repo 提供網站原始碼；託管平台的存取權限及部署設定另行配置。

## 驗證

使用支援 `node:test` 的 Node.js：

```sh
node --test tests/core.test.cjs tests/app-smoke.test.cjs
node --check dist/app.js
```

目前有 13 項程式與資料流程檢查，涵蓋題目證據範圍、例答分數、草稿保留、修訂後自評清除、完成條件、教師題目建立及無效匯入資料。

`app-smoke.test.cjs` 使用輕量 DOM 模擬，檢查頁面產生及事件／資料流程；它不代表實際瀏覽器排版、CSS 或手機操作已完成驗證。
