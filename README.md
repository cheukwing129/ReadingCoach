# 閱讀答題教練 ReadingCoach

正式網站：[閱讀答題教練](https://readingcoach.pages.dev/#home)

以學生自主學習為定位，按**年份 → 文章 → 原題**組織 DSE 白話文閱讀。學生逐題辨認主要題型，按需打開方法及本題提示，再作答、練習評分及閱讀解析，把解題方法帶到其他文章。

## 學生流程

1. **辨認題型**：按題幹的主要任務選題型，收到解釋。方法提示預設收起，點擊才展開。
2. **找線索及作答**：答題步驟和具體提示分開；本題提示逐層展開，提供思考問題及原段落定位，未直接披露答案。
3. **評分練習**：可先不作答。每個書面分題至少四個示例，4分長答分題各有0–4分示例；分數預先隱藏、順序打散，評完才公佈。學生已有答案加入比較；與例答相同的短答只列一次。
4. **閱讀解析**：逐例說明分數及評分差距；選擇題省略例答評分，逐項解釋正誤。對照準則自檢，整理可遷移方法及選填一句學習筆記。讀完各示例後記下完成進度，同篇下一題可直接繼續。

首頁、文章列表及下一題不自動導向其他年份。來源／出處說明、教師批改、檔案交換、學習記錄匯出、能力認證及跨年挑戰已退出公開介面。

## 分數的邊界

示例的已知得分按既有評分資料核對。新增45份長答例答，每個4分長答分題覆蓋0–4分；短答例答依接受／欠準確／不給分答案分類。講解是依題目及準則整理的教學分析。

未與已知例答相同的自由答案**不會得到虛構的自動語意分數**，會保留學生自評並顯示準則及自檢項目。兩字詞格式可以按題目明定規則核對，但符合格式並不保證理解正確。沒有模型服務或教師批改流程。

2025第20題(iii)仍保留(ii)是否已得分的特殊規則；不能將重複寫領悟當作一般的闡述得分。

## 本機保存及相容

新資料使用 `readingcoach-self-study-v1`，保存每題的題型、答案、例答評分、解析閱讀狀態、筆記和進度。初次使用新版本時遷移已收錄題目的舊草稿及先前首答；舊 `dse-reading-coach-v1` 原封保留，不刪除退休題目的歷史資料。

答案重寫會使舊評分揭示、閱讀確認和完成進度失效，避免舊評分對應新答案。草稿在這個瀏覽器自動保存；拒絕儲存或容量不足時顯示提示，可繼續本次練習，但沒有跨裝置同步。

## 開發及驗證

原生 HTML/CSS/JavaScript，無建置依賴。根目錄與 `dist/index.html` 共用同一版本的資料及程式。現有 Cloudflare Pages 部署設定不需更動。

```sh
python -m http.server 8080
node --test tests/*.test.cjs
```

瀏覽器驗證需可用的 Chromium、Playwright 及繁體中文字型：

```sh
PLAYWRIGHT_MODULE_PATH=/path/to/playwright-core BROWSER_EXECUTABLE_PATH=/path/to/chromium node scripts/self-study-browser-smoke.cjs
```

可用 `BROWSER_QA_OUTPUT_DIR` 設定驗證畫面位置。新流程測試見 `tests/self-study.test.cjs`；資料核對及歷史程式測試一併保留，舊教師流程的測試不代表該流程仍公開。詳細變更見 `docs/2026-10-11-self-study-rebuild.md`。
