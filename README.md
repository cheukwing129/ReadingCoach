## 年份密碼設定

進入年份目錄、文章或題目直達連結前都會檢查解鎖狀態。2012–2030 預設密碼為每年不同的英文名加年份；在一個瀏覽器解鎖後，會以 `localStorage` 記住該年。教師通行碼可解鎖全部年份，亦只會在目前瀏覽器記住。密碼以 SHA-256 雜湊存於 `dist/year-access-config.js`，不會以明文放進網頁。

更改密碼時，使用本機終端機產生新雜湊（輸入時不會顯示密碼），再替換該年 `years` 或 `teacher` 欄位：

```sh
python3 -c 'import getpass,hashlib; print(hashlib.sha256(getpass.getpass("新密碼：").encode()).hexdigest())'
```

這是靜態網站的輕量進入提示；頁面資料仍隨網站程式下載，不能用來保護機密內容。

## 學生流程

選取篇章後先進入原文頁。二十二篇白話文共240段，保留原文件的分段與編號，包括2013第一篇第10段的十七行〈尋人啟事〉、2021第二篇第6段的四行引詩、《比正路還長的巷子》第9段的七行、2022第二篇第4段的引詩，以及《一竿冷》第1段詩句與正文分行、第3段跨頁的原段落。2022文言保留三則原標示及第三則三個原分段；2023文言保留「第三篇」原標示與完整未分段原文；2024及2025文言各自保留「第一則」「第二則」原標示，不新增原段號。頂端逐段／逐則分析預設不勾選；開啟後只顯示每段或每則的展開按鈕，學生再點擊才看到內容大意、手法、深層意思及結構。關閉總開關會移除所有分析，重新進入或重新整理亦預設關閉。

1. **辨認題型**：每個選項顯示該題型的具體特徵，按題幹的主要任務選擇。方法提示預設收起，點擊才展開。
2. **找線索及作答**：答題步驟和具體提示分開；本題提示逐層展開，提供思考問題及原段落定位，未直接披露答案。
3. **評分練習**：可先不作答。有評分例答的書面分題至少四個示例；分段範圍直接核對原標準答案，4分長答依原評卷參考收錄各品第示例；2016第7題兩欄沒有獨立1分例答，保留0、2、3、4分；2016第8題及2017第8題沒有獨立3分例答，保留0、1、2、4分而不編造；分數預先隱藏、順序打散，評完才公佈。學生已有答案加入比較；與例答相同的短答只列一次。
4. **閱讀解析**：逐例說明分數及評分差距；選擇題省略例答評分，逐項解釋正誤。對照準則自檢，整理可遷移方法及選填一句學習筆記。解析公佈後可直接完成本題，再繼續同篇下一題；沒有逐例「我明白」勾選門檻。

首頁、文章列表及下一題不自動導向其他年份。來源／出處說明、教師批改、檔案交換、學習記錄匯出、能力認證及跨年挑戰已退出公開介面。

## 閱讀與教學版面

可用尺寸至少960 × 540且為橫屏時，原文固定在左欄、題目與教學在右欄，原文可獨立捲動。直屏或空間不足時使用「原文／題目與教學」分頁，支援方向鍵切換。切換分頁及旋轉屏幕只改變顯示方式，不卸載答案輸入欄。

題目在下拉時固定於教學欄頂部，按視窗尺寸縮小字體與留白，並自動避開網站標題及分頁列。長引文與表格保留全文，可在題目框內捲動，亦支援鍵盤操作。切換至原文分頁時不顯示題目框。

題幹、引文、表格或分題中的段落編號會自動定位並標示；表格有已填示例時優先定位本題需解答的段落。提示內的段落按鈕亦可切換到原文並定位，返回教學後保留草稿和閱讀位置。

2022第17題在同一個題目頁提供兩篇原文切換，預設顯示須分析的第一篇。第二篇只提供「揚棄」的概念；相關段落按鈕標明篇名，兩篇相同段號不會混用。切換篇章只更新原文欄，保留答案、提示和教學步驟。

2019第16題提供兩篇切換，選一篇說明諷刺特點與欣賞原因即可，沒有強制兼論兩篇。第一篇保留原卷寫作背景及28個原分段，新增段號明示只供網站定位。

2021第15、16題同樣提供兩篇切換，原段號分開核對；第15題預設第一篇、第16題預設第二篇。

## 本機保存及相容

新資料使用 `readingcoach-self-study-v1`，保存每題的題型、答案、例答評分、提示使用狀態、筆記和進度。初次使用新版本時遷移已收錄題目的舊草稿及先前首答；舊 `dse-reading-coach-v1` 原封保留，不刪除退休題目的歷史資料。

答案重寫會使舊評分揭示和完成進度失效，避免舊評分對應新答案。草稿在這個瀏覽器自動保存；拒絕儲存或容量不足時顯示提示，可繼續本次練習，但沒有跨裝置同步。

## 開發及驗證

原生 HTML/CSS/JavaScript，正式頁面不依賴執行時建置。Lumen Elements 4.0.0 的 Button、Card 與官方樣式已預先打包於 `dist/vendor/`；只在更新這些資源時執行 `npm ci && npm run build:ui`。根目錄與 `dist/index.html` 共用同一版本的資料及程式。現有 Cloudflare Pages 部署設定不需更動。

```sh
python -m http.server 8080
node --test tests/*.test.cjs
```

瀏覽器驗證需可用的 Chromium、Playwright 及繁體中文字型：

```sh
PLAYWRIGHT_MODULE_PATH=/path/to/playwright-core BROWSER_EXECUTABLE_PATH=/path/to/chromium node scripts/self-study-browser-smoke.cjs
```

## Lumen UI 全站設計（2026-10-12）

全站沿用已選定 demo 的青綠配色、白底閱讀卡片、宋體篇章標題及精簡導覽。包括年份目錄、文章原文、逐題目錄、辨認題型、作答、例答評分與解析；十九篇原文、135道題目和既有學習資料均保留。

1280px以上使用側欄；較窄螢幕使用頂部導覽。原有橫屏雙欄／直屏分頁與黏性題目仍由原程式管理。文章和題目原文均可調整14–26px字體，另以 `readingcoach-font-size` 保存設定，不改動原有草稿鍵。

動畫限於180–220ms內容淡入、按鈕回饋、分析展開和選取切換；沒有滾動視差或持續動畫。`prefers-reduced-motion` 會關閉動畫，sticky祖先不會套用transform。

Lumen官方樣式使用semantic tokens。原有native答題控制保留disabled、label、change與localStorage流程，新字體按鈕和年份卡片使用正式Lumen Web Components。開發依賴有固定版本，部署使用已提交vendor檔案。
